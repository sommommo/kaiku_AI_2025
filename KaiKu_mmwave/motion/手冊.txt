1. 系統用途

這套系統可用來做：

即時 mmWave 資料擷取

人體 target bin 自動選擇

motion energy 計算

phase / 呼吸 / 心跳訊號觀察

跌倒 / 咳嗽事件 baseline 偵測

事件 segment 自動存檔

離線切窗建立資料集

訓練分類模型

用模型預測 segment 類別

4. 執行前準備
4.1 修改 setting 路徑

先打開 config.py，修改：

setting_dir = r"...你的 TempParam 路徑..."

例如你目前可能會用：

K60168-Test-00256-008-v0.0.8-20230717_120cm

如果你主要要做跌倒 / 大動作，先試 120cm。
如果主要看 phase 微動 / 呼吸 / 咳嗽，再試 60cm。

4.2 安裝必要套件

至少要有：

pip install numpy

如果要 GUI：

pip install pyqtgraph PyQt5

如果要訓練模型：

pip install scikit-learn joblib
4.3 確認 KKT 環境

你必須能正常 import：

from KKT_Module import kgl

如果這裡失敗，代表 KKT SDK 或環境還沒設好。

7. 第二步：離線切窗建立資料集

如果你錄了一大段 session，想手動指定某一段是 fall 或 normal，可以用：

python offline_review.py --session_npz OutputResearchSystem/session_xxx/raw_frames.npz --label fall --window_sec 2.0 --stride_sec 0.25
常用參數
指定 session 檔
--session_npz
指定標籤
--label fall

可用 label 建議：

fall

cough

sit

normal

bend

walk

視窗長度
--window_sec 2.0
滑動步長
--stride_sec 0.25
指定切某段時間
--start_sec 5
--end_sec 12

例如：

python offline_review.py --session_npz OutputResearchSystem/session_20260310_100000/raw_frames.npz --label fall --window_sec 2.0 --stride_sec 0.25 --start_sec 8 --end_sec 15

意思是只把第 8~15 秒切成 fall 視窗。

12. 重要參數說明

在 config.py 裡最常調的是：

motion_z_fall

跌倒事件門檻。
越大越不容易觸發。

motion_z_cough

咳嗽 burst 門檻。
越小越敏感。

cough_min_bursts

短時間內要出現幾次 burst 才算 cough。

fall_still_sec

跌倒後要持續低活動多久。

fft_bins

range FFT 使用的 bin 數。

ignore_bins

忽略近距離直流或雜波 bin。

13. 常見問題
Q1：GUI 沒出來

先確認安裝：

pip install pyqtgraph PyQt5

如果沒有 GUI 套件，系統會自動 headless 執行。

Q2：一直抓不到 target bin

先檢查：

人體是否在有效距離內

setting_dir 是否選對

120cm / 60cm 是否適合目前場景

ignore_bins 是否設太高

Q3：跌倒和快速坐下分不清

這很正常。
先多收：

sit

bend

normal

再訓練模型，不要只靠規則式。

Q4：咳嗽很難抓

只靠 mmWave 本來就難。
目前比較適合先做：

cough-like burst event

上半身異常急促動作

不要一開始就要求精準嗆咳分類。

Q5：為什麼 120cm 比較適合跌倒

因為跌倒 / 大動作通常需要看更完整的人體位移，不只是近距離胸腔微動。
所以大動作先試 120cm 比較合理。

14. 推薦操作順序

你現在最推薦這樣做：

第 1 天

跑 main.py

第 3 天

用 offline_review.py 切資料

第 4 天

用 train_model.py 訓練

第 5 天

用 predict_model.py 驗證
